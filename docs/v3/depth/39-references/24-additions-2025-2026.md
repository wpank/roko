## Cross-Cutting Themes

### Theme 1: Sleep-Time Compute is Production Engineering
Twelve 2025--2026 papers demonstrate offline consolidation produces measurable gains: 38% less forgetting, 18% accuracy, 117x token savings. Dreams is engineering, not speculation.

### Theme 2: Active Forgetting Outperforms Accumulation
Memory surveys and SleepGate/FadeMem/MemPro converge: forgetting is a feature. Naive add-all degrades performance. The Curator cycle is validated.

### Theme 3: Explicit Coordination Beats Implicit Cooperation
2025--2026 papers show 41--87% of multi-agent failures are coordination, not capability. LLMs fail at implicit coordination. Roko's Pheromone Field and Agent Mesh are the right response.

### Theme 4: Scaffold Choice Equals Model Choice
Meta-Harness, HAL, and Natural-Language Harnesses show 6x performance from scaffold changes alone. Model leaderboards mislead. Roko is a scaffold system.

### Theme 5: Process Verification Enables Self-Improvement
AgentPRM, GEPA, and Mind-the-Gap confirm: self-improvement works only when verification exceeds generation. The Gate pipeline is architecturally necessary.
