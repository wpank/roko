# Citation Explorer

Roko's v3 documentation draws on 440+ academic and industry references spanning
evolutionary biology, neuroscience, cognitive psychology, computer science, machine
learning, philosophy, economics, mechanism design, cybernetics, active inference, HDC,
DeFi, regulatory compliance, and agent engineering. Every entry links to the Roko
subsystem it informs.

Use the filters below to search by topic section, year range, author, or full text.
Select entries and export them as BibTeX for your own work.

For the full unstructured bibliography, see [REFERENCES.md](../REFERENCES.md).
For per-chapter bibliographies, see the **References** sections in each v3 chapter.
