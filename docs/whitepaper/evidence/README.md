# Frozen evidence

The whitepaper cites only tracked files. Anything it quotes from a gitignored source is copied here and fixed by
its sha256, so that a reader can check the quote against the exact bytes the text was written from.

- **Check the files:** `cd docs/whitepaper/evidence && shasum -a 256 -c SHA256SUMS`.
- **What may be frozen:** derived, scrubbed data only: counts, rollups, tables and case write-ups. Never
  transcripts, prompts, environment dumps, or anything that could hold a key (bug-7d7200).
- **No absolute paths:** rewrite any absolute path in a source (a home directory holds the user's name) to a
  repo-relative one, or drop it, before freezing, and take the sha256 after scrubbing; the file's row says what was
  rewritten. Check with `grep -rnE '/(Users|home|private)/' docs/whitepaper/evidence/`, which should print nothing.
  Only the two 2026-10-02 notes below contained one (a session scratchpad under the system temp directory, whose name
  holds the user's); their rows say what was rewritten.
- **Names:** `<YYYY-MM-DD>-<slug>.<ext>`, dated by when the source generated it.
- **Only cited files:** every file here is cited by a footnote in §7. On 2026-10-16 the review of the 2026-10-02
  rewrite (gap-6a83de) removed the seven files that no section cited any longer: the field rollup (`.md` and
  `.json`) and its README, the S09 H1-bar excerpt, the W12 operator-loop estimate, and both B5 learning-loop tables.
  Git history keeps them, and the earlier reviews in `../REVIEW.md` name them as they were.
- **Never edit a frozen file.** To refresh one, freeze a new dated file, add its row and its `SHA256SUMS` line, and
  update the footnotes that cite it.
- This `README.md` and `SHA256SUMS` are the only files here that change. `SHA256SUMS` lists every frozen file and
  neither of these two.
- gap-29a64e (§7) created this directory. Other sections add their files and rows in small commits of their own.
