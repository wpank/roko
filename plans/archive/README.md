# Completed plan archive

This directory contains plan directories moved out of the active `plans/`
queue after successful completion. Roko's plan loader scans only immediate
children of `plans/`, so these nested plans are retained for reference without
being selected by broad plan runs.

Archived on 2026-09-01: 64 plans.

To run an archived plan again, move its directory back to `plans/` and reset
its task metadata as appropriate.
