# Incident tabletop demo

This example turns repository evidence into an operational tabletop exercise.
It demonstrates CSV analysis, structured scenario design, human facilitation
material, cross-artifact checks, and a final read-only review.

The four stages are intentionally sequential so every attempt inherits the
accepted artifacts from the preceding stage.
